# Two-minute demo script

1. Show the tokenized graph and explain that names are never displayed.
2. Point to the cluster score and the explanation panel.
3. Download the sample CSV and upload it for live analysis.
4. Issue an attestation as Company A.
5. Issue another as Company B.
6. Revoke one claim and show the lifecycle state.
7. Close with: “The graph stays private; the blockchain stores only verifiable claims.”
